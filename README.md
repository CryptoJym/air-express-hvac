# Air Express Public Visibility Report

This directory is the sanitized GitHub Pages layer for Air Express visibility reporting.

It is safe to publish after review because it contains client-facing summaries, score data, and action labels only. Raw provider exports, private lead evidence, local run logs, credential material, browser/session material, and private customer records stay out of this directory.

- `index.html`
- `pages/air-express-seo-geo-visibility-score.html`
- `pages/air-express-weekly-impact-2026-06-15.html`
